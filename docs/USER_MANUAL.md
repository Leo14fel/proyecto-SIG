# Manual de usuario

1. Inicie sesión con una cuenta activa. El panel muestra los conteos SQL de Manzanas, Lotes, Códigos Fijos y Vías.
2. Abra **Visor** y active las capas necesarias. Lotes requiere zoom 16 y carga solo la extensión visible.
3. Para una búsqueda rápida, deje **Todas** y escriba, por ejemplo, `AGUILAR`. Para filtrar una capa, selecciónela, elija Campo, Operador y Valor.
4. Use la paginación y **Ver en mapa** para acercar y resaltar un resultado. Al pulsar una geometría, el detalle permanece visible hasta limpiar la selección.
5. Use **Exportar resultados a CSV** para descargar el conjunto filtrado, hasta el límite de seguridad del servidor.
6. **Mi perfil** muestra identidad, rol y estado, y permite cambiar la contraseña con la contraseña actual.
7. Los administradores disponen de **Administración** para consultar usuarios, roles y activar/desactivar cuentas. Los consultores no tienen acceso a esa ruta.
8. Cierre sesión desde la navegación superior al terminar.
